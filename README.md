## Estado actual

Este repositorio todavía no incluye código fuente, firmware, una aplicación ni archivos ejecutables. Por ahora contiene este README y configuración de GitHub. El repositorio, por sí solo, no se conecta a un adaptador ELM327 ni ofrece lectura de datos o diagnósticos del vehículo.

No hay instrucciones de instalación o uso porque aún no se publica un programa que pueda ejecutarse.

## Seguridad

No publiques credenciales, números de identificación del vehículo ni registros con datos personales. Si más adelante se añade software para vehículos, explica qué datos utiliza y valida su funcionamiento antes de presentarlo como herramienta de diagnóstico o reparación.
